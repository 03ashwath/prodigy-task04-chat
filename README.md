# Real-Time Chat Application

A real-time chat application using WebSockets via SignalR.

## Features
- Real-time messaging using SignalR (WebSockets)
- Multiple chat rooms
- Private direct messaging
- Online/Offline user presence indicators
- Typing indicators
- Chat history saved in database
- Push notifications

## Tech Stack
ASP.NET Core | SignalR | SQL Server | Entity Framework Core | JWT | HTML/CSS/JS
